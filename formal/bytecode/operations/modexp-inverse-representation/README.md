Modular inverse mathematical representation bridges

Reuses the independently checked source Euclid arithmetic as mathematics, connecting unsigned quotient/remainder, checked coefficient bounds and wrapped signed updates to the normative word representation. Actual compiled inverse instruction traces, control, termination and public errors remain open. These bridges have no native result yet and cannot be used to infer bytecode, compiler, gas, deployment or performance claims. The complete imported native/declaration/source generation closure must be retained before public use.
