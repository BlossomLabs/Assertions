# Operations rawCall source correspondence

The complete `rawCall` and `_rejectOutOfGas` compiler ASTs, including the header-read assembly and exact error selectors, are gated. Source-derived success, exact-length signal and exhaustion predicates drive the native connection theorem: success returns original returndata, failed exhausted/exact-signaled calls produce SubcallOutOfGas, and every other failure wraps the original requested target and calldata. A longer returndata beginning with the signal is ordinary failure when resources remain.

The observation receipt must identify the exact requested target/input, actual staticcall success and original returndata, gas measured before the call and gas measured inside the guard. It must faithfully represent execution in the actual call context. The header assembly projects the first four bytes of a valid memory byte object when its length is four. Valid decoded addresses, nonwrapping disjoint memory, faithful call/byte/gas projections and restricted source lowering, exact outer ABI/error serialization and adequate local resources remain premises. This conditional source theorem does not prove a gas schedule or guarantee behavior of targets that swallow/transform failures or branch on gas. Code-less accounts and precompiles are admitted; no code-length check is inferred.

Retained checks include fresh native declarations/CSV, zero audit, six real EVM tests covering echo, ordinary rejection, exact signal and long prefix, code-less accounts, the identity precompile and gas exhaustion. Two semantic source faults must translate and fail both native semantics and EVM fixtures. Exact runtime bytecode, deployment, gas availability and performance remain separate.
