# sortWords reached arithmetic helpers

The owned generator extracts the actual Mod, Div32, checked doubling, checked addition and index increment helper instructions, with every legal reached sortWords return destination pinned. Arbitrary stack prefixes and original memory are preserved. Nonwrapping conditions are explicit and must be discharged by the body invariant.

Development only. Complete loop, physical output and retained evidence remain open. No public-bytecode, gas or performance claim. Never edit generated outputs and finish package files before snapshotting.
