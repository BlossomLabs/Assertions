# unpackArray encoded-value physical copy

Generate the exact actual runtime path from admitted library wrapper PC7262to AbiCodec.unpack PC12814. Arbitrary represented calldata offset/length, lower stack prefix and memory are preserved through rounded allocation, length word, CALLDATACOPY and zero padding. The generic existing checked physical memory/arithmetic kernels are reused without editing their owners. Full descriptor parsing, canonical array/value/error/loop semantics and returned serialization remain open. Native and independent retained checking are required; no public credit.

The handwritten boundary composes the complete raw PCzero decoder with the physical copy. Every raw decoder failure remains exact empty REVERT; every accepted raw frame reaches actual AbiCodec.unpack PC12814with complete length/payload/padding memory. The descriptor parser and array body are not summarized as proved.
