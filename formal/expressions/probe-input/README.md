# Probe operand decoding

ProbeOperandType derives the second operand's ABI Bytes type from graph
admission, backward references and descriptor correspondence. The hash premise
is explicit and limited to descriptors in the current graph: a hash equal to
the bytes descriptor's hash identifies that descriptor. No universal hash
injectivity or collision theorem is asserted. Parser completeness proves the
descriptor identity rather than assuming its syntax tree.

CanonicalDecode derives the standard 0x20 offset, in-bounds length and exact
payload from independent canonical validation, and proves re-encoding gives
the original operand. Probe feeds those payload bytes into the already-proved
probe receipt adapter. Exact success envelopes, failure bytes and request
history therefore use the decoded calldata, not its enclosing ABI bytes object.
Decodable is listed explicitly wherever the partial DecodeBytes projection is
used in a method contract; CanonicalDecode proves it from the preceding
canonicality and size conditions.

Solidity's compiler-generated bytes decoder is assumed to implement the
standard projection on canonical data; its bytecode and treatment of arbitrary
noncanonical input are not proved here. Representable input/output allocations,
faithful external context/gas observations and sufficient resources remain
premises. Target address checking precedes this adapter in the separately
proved request contract. Full primitive oracle and graph entrypoint/frame
composition remain open.

Six EVM tests use a target that reverts with exactly its calldata, exercising
empty, short, selector-width, aligned, unaligned and multiword payloads. The
baseline audits native proof/declaration inventories and all reused dependency
source/tool/evidence hashes. No new actual-source mutation campaign is claimed.
