# Sort result serializer, development only

The serializer admits an arbitrary rounded reached heap with its free pointer, bytes header, payload extent and source payload explicitly proved. It returns the exact dynamic ABI bytes envelope by the actual header stores, MCOPY, trailing store and RETURN. This covers either physical sort buffer and preserves the entire other buffer. Fitting memory, faithful opcode interpretation and reached resources remain premises. Complete sort body composition and retained evidence remain open; no public coverage increment follows.
