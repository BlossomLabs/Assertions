# Operations word matcher and contains — conditional source evidence

This package targets `contains(bytes,bytes)` and the complete reached `_matchesAt` assembly body. `generate.py` pins both full ASTs, source/compiler/tool identities and the public compiler selector. It derives caller controls, wrapped calldata address calculations, helper loop limits/increments, tail subtraction, `SHL`/`SHR` operands and mismatch comparisons from AST nodes. Generated controls must be regenerated, never edited.

The independent model defines byte-window equality and existential substring occurrence. Its quantified proofs establish big-endian packing bounds and injectivity, prefix extraction by integer division and EVM right shifts, and word/tail window projections. The actual helper loop accumulates exact prefix equality, rejects a differing chunk, and covers the final partial word. The caller admits empty needles, rejects an oversized needle and examines every possible start position. No internal matcher postcondition or byte-padding value is assumed.

Representation premises are valid decoded byte strings, lengths below `2^255`, actual calldata offsets and nonwrapping address frames through a possible 32-byte load. A load faithfully projects 32 big-endian calldata bytes. Bytes beyond each input window are arbitrary: the proof removes them before comparing a partial chunk. EVM ADD/SUB/SHL/SHR/LT/EQ/ISZERO, source bool/default initialization, checked caller increment, and outer bool ABI serialization are primitive correspondence premises. The restricted AST lowering is reviewed source correspondence, not a certified Solidity compiler translation. Trusted Dafny/Boogie/Z3 and adequate verification/execution resources remain explicit. There is no exact-bytecode, gas, deployment, performance or cross-context observation claim.

`verify.py` freezes every direct package file, the closed native graph, compiler sources and tool identities. It retains regenerated controls, fresh verification of every declaration, CSV inventories, zero audit findings, format checks, EVM fixtures and a semantic source-fault campaign. Faults must compile and translate, then fail a native semantic obligation and a real EVM oracle; parse errors and timeouts are incomplete. `check-evidence.py` independently checks current inputs, frozen snapshots, all artifact hashes, native inventories and receipts, and exact current regeneration. Coverage is counted only after both pass.

The two EVM fixtures include empty and oversized inputs, final positions, binary/zero bytes, lengths spanning 31/32/33/64/65-byte boundaries and partial-word near misses. The source faults change the tail shift from three to two bits and invert the caller match test. Development failures are preserved separately and are not public evidence.
