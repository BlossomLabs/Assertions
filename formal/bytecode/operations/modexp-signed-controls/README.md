# Signed-base modular-power wrapper preparation

These seven compiler-bound paths cover both operand magnitude conversions for all sign combinations and all three actual signed-result control paths. Their contracts retain exact physical stacks, memory, instruction transitions and terminal ABI bytes. The independent signed model includes both minimum signed operands.

Generation, formatting, resolution and audit gates are preparation. Native verification and the complete retained public dependency graph remain pending; these files provide no public bytecode credit.
