# Operations split — conditional source evidence

This package targets the complete `split(bytes,bytes)` public AST, compiler selector and generated controls. Its generator independently gates/regenerates the immutable reached count and matcher packages. Generated files are never hand edited.

The independent recursive segment specification consumes exact non-overlapping byte matches, preserves the bytes before each match and includes the final tail. Its quantified properties connect the number of segments to the proved occurrence enumeration and show that joining the parts with the delimiter reconstructs the original data. The actual source allocation/fill loop maintains an exact written-prefix plus remaining-segments invariant. It fills exactly count plus one parts, including leading, trailing and adjacent empty segments; an empty delimiter produces `EmptyNeedle` before allocation. Actual count and assembly matcher bodies are freshly verified in the closed native graph, with no assumed mathematical helper postcondition.

Representation/resource premises are valid decoded calldata, data length plus one below 2^255 and delimiter length below 2^255, actual offsets/nonwrapping 32-byte load frames, exact primitive/source arithmetic and byte projections, successful sized array/segment allocations, faithful default initialization, exact slice-to-memory projections and outer bytes[]/EmptyNeedle ABI serialization. Bytes outside each input window are arbitrary. Allocation/resource failures are outside the successful-allocation premise. Reviewed restricted AST lowering and trusted native tools remain conditional correspondence premises; no compiler-correctness, exact-bytecode, gas, deployment or performance claim follows.

The retained verifier freezes all direct package files, the reached dependency packages, compiler sources and tool identities. It retains exact regeneration, every native declaration/CSV obligation, zero audit findings, format checks, two EVM fixtures and two semantic source mutations. EVM fixtures cover empty delimiter rejection, empty/leading/adjacent/trailing parts, absent and oversized delimiters, binary bytes and non-overlap. Mutations include the delimiter in a part and copy the wrong final tail; each must compile/translate and fail an independent literal semantic witness using the actual AST-derived slice operand plus an EVM oracle. These witnesses call no potentially false mutated helper contract; the complete original quantified source loop remains freshly verified. Parse errors/timeouts are incomplete. An independent checker verifies current/frozen inputs, all artifact hashes/inventories/receipts and exact regeneration before coverage is recorded. Failed development/retained runs remain preserved.
