# Operations replace — conditional source evidence

This package targets the full `replace(bytes,bytes,bytes)` public AST and compiler selector. Its generator derives controls, recorded-match capacity, output sizing, write offsets and actual copy-source operands from compiler AST nodes. It independently gates/regenerates the immutable count/matcher and concat/copy packages. A mechanically generated ghost mirror of the exact matcher body composes with the ghost memory-copy model; every mirrored assertion and helper body is freshly verified. Generated files are never hand edited.

The independent specification replaces the proved greedy non-overlapping occurrence positions with the replacement bytes, preserving every intervening gap and final tail. Quantified properties prove ordered/disjoint positions, consumed-byte bounds, record capacity and exact rendered length. The actual first source loop fills the recorded positions once. Source checked sizing detects multiplication/addition overflow; the second loop maintains exact output-prefix and remaining-render invariants, calling the actual proved `_copy` body for gaps, replacements and tail. That helper's AST-derived destination/length and universal header/outside memory frames are freshly proved. Empty needles reject before allocation; no matches preserve the original bytes. No internal mathematical helper postcondition is assumed.

Explicit representation/resource premises are valid decoded calldata; haystack length plus one below 2^255, needle length below 2^255 and replacement length below 2^256; actual nonwrapping 32-byte calldata frames; faithful EVM/source integer, shift, comparison and byte projections; successful sized match-array/output allocations including compiler allocation limits; faithful source defaults and slice-to-memory projection; an aligned nonwrapping output/free-pointer frame; and outer bytes/EmptyNeedle/Panic ABI serialization. Arithmetic overflow is proved, while allocation/resource failures are outside the successful-allocation premise. Bytes beyond input windows are arbitrary. Trusted native tools and reviewed restricted AST lowering remain conditional correspondence premises. No certified compiler, exact-bytecode, gas, deployment or performance claim follows.

The retained verifier freezes all direct and reached dependency package files, compiler sources and tool identities. It retains exact regeneration of both generated files, every native declaration/CSV batch, zero audit, format checks, EVM fixtures and compiler-admissible semantic mutations. EVM fixtures cover expansion, contraction, deletion, non-overlap, unchanged inputs, binary bytes and empty-needle rejection. Mutations calculate the wrong output size and copy the needle instead of the replacement. Each must compile/translate, fail an independent literal witness using the actual AST-derived operand (without calling a false helper contract), and fail a real EVM oracle. The complete original quantified loop graph remains freshly verified. Parse errors/timeouts are incomplete. The independent checker verifies current/frozen inputs, all hashes/inventories/receipts and both exact regenerated files before coverage is counted. Failed development/retained snapshots remain preserved.
