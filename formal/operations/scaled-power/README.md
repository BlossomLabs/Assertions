# Operations rpow conditional source evidence

This package covers `rpow(uint256,uint256,uint256)` at the decoded ABI boundary. Its independent recursive specification is the precise binary scaled-power rounding trace: each selected multiply and each required square takes floor(fullProduct/base), and the first unrepresentable intermediate produces Panic(0x11). A zero scale produces Panic(0x12) even on the empty exponent; zero input with zero exponent produces one scale unit. For example, rpow(4,3,3) is 6 after the actual per-step floors, whereas rounding 4^3/3^2 once gives 7. This trace is not claimed equal to an ideal real power or to have an error bounded by the number of operations.

`Model.dfy` gives the recursive trace, complete edge behavior, termination and result/error range. `Control.template.dfy` models the actual public source loop, including selected multiplication, exponent shift, conditional square, error propagation, zero paths and final result. Its loop invariant connects every reached state to the independent trace. `Connection.dfy` proves full public result/error classification for every decoded 256-bit x/exponent/scale.

`generate.py` gates the complete public body and compiler-bound selector, and checks both Math.mulDiv calls and the _panic call against their actual compiler declaration targets. It freshly invokes the full-mul-div generator and requires byte-identical generated source/helper controls. The entire reached full-domain Math.mulDiv graph, including CRT, twos normalization, disjoint OR, inverse seed/six Hensel steps, exact quotient and both assembly panic payloads, is included and freshly verified by the retained native run. A local `Step` theorem connects that proved helper body to the per-step trace; its semantics is not assumed. Never edit generated source files; edit the template or generator.

The boundary assumptions are trustworthy compiler AST/selectors and reviewed restricted source correspondence (not a certified translator); faithful decoded uint256/control/AND/SHR and checked/wrapping primitive representations; outer successful ABI and compiler-generated panic serialization; adequate memory/resources; and trusted Dafny/Boogie/Z3. The reached explicit _panic helper's bytes are freshly derived from actual MSTORE and REVERT. No exact-bytecode, compiler correctness, gas, deployment or performance claim follows.

`verify.py` freezes all direct package files, dependency generator/templates/controls, full include graph, source/AST/compiler/tool inputs before retaining source regeneration, every included native declaration/result, zero-findings audit, formatting, two EVM fixtures and two source faults. The fixtures pin zero/empty/max-exponent behavior, actual rounding losses, full-width scaled intermediates and exact panic bytes. The exponent-shift and scaled-square operand mutations must compile and translate, fail independent native witnesses using unchanged proved arithmetic helpers, and fail real EVM oracle assertions. Parse/type errors, timeout or resource failure do not count as detection.

`check-evidence.py` independently checks current/frozen inputs, hashes, native declaration/CSV and EVM/fault inventories, all retained receipts, and fresh regeneration. Public coverage requires terminal passed retention and a passed checker. Failed development snapshots remain preserved under `development/` and carry no completed coverage claim.
