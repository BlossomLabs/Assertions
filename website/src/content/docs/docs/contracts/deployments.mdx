import { getCollection } from 'astro:content';
import manifest from '../../../../lib/deployments.json';
import DeploymentsApp from '../../../../components/deployments/DeploymentsApp';
import '../../../../styles/deployments-island.css';

export const releases = await getCollection('releases');
export const releaseFor = (version) => releases.find((r) => r.data.version === version);

Assertions work on a chain once the four contracts are deployed there.

## Addresses

The addresses are the same on every chain.

<table>
  <thead>
    <tr><th>Contract</th><th>Version</th><th>Address</th><th>Released in</th></tr>
  </thead>
  <tbody>
    {manifest.contracts.map((c) => (
      <tr key={c.key}>
        <td>{c.name}</td>
        <td>{c.version}</td>
        <td><code>{c.address}</code></td>
        <td>{releaseFor(c.version) ? <a href={`/releases/${releaseFor(c.version).id}`}>{releaseFor(c.version).data.codename}</a> : null}{releaseFor(c.version)?.data.date ? ` · ${releaseFor(c.version).data.date}` : ''}{releaseFor(c.version)?.data.status === 'upcoming' ? ' (upcoming)' : ''}</td>
      </tr>
    ))}
  </tbody>
</table>

The builder uses them for you. If you build calls by hand, copy them from here.

## Networks

Each status is read live from the chain. **Deployed** opens the contract on the chain's explorer. **Pending deployment** takes you to the steps below, where anyone can deploy the contracts.

## ENS names

Every contract has two ENS names. The release name is permanent: it keeps resolving to that release's contract after a later one ships. The bare name always resolves to the newest release, so it moves when one ships.

<table>
  <thead>
    <tr><th>Contract</th><th>Version</th><th>Release name</th><th>Bare name</th></tr>
  </thead>
  <tbody>
    {[...manifest.contracts, ...manifest.history].filter((c) => c.ens).map((c) => (
      <tr key={c.ens}>
        <td>{c.name}</td>
        <td>{c.version}{releaseFor(c.version) ? <> (<a href={`/releases/${releaseFor(c.version).id}`}>{releaseFor(c.version).data.codename}</a>)</> : null}</td>
        <td><code>{c.ens}</code></td>
        <td>{c.ensLatest ? <code>{c.ensLatest}</code> : 'Moved to a later release'}</td>
      </tr>
    ))}
  </tbody>
</table>

Use a release name wherever the contract must never change under you.
