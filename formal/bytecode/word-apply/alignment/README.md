# Word apply aligned-source prefix

The generator pins both public selectors and every reached instruction of the actual shared application prefix, including the checked MOD helper and its branch. For any source length divisible by32, all decoded Word fields, arbitrary lower stack and memory, the path reaches the actual element-window entry atPC16683 with unchanged memory. No calldata canonicality, target validity or window validity is assumed here: those are checked by later fragments.

This is partial development evidence. Exact UnalignedWords receipts, window errors, allocation, target admission, callback execution, output and complete raw public retention remain separate obligations. No gas, deployment or performance claim follows.
