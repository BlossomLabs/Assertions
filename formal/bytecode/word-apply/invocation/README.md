# Decoded wrapper invocation development

`generate.py` gates the exact compiled Collections runtime hash and both map/filter selectors, then extracts the actual code paths from decoded map wrapper PC1050 and filter wrapper PC784 to shared body PC12177. Every reached instruction and complete stack is retained. The accepted raw decoder returns seven arguments; the wrapper preserves those arguments below the call frame, adds the compiler's96 return placeholder and5526 return PC, copies all seven arguments and supplies mode0 or1. Arbitrary lower stack prefixes and memory are preserved. The generic invocation theorem quantifies over all Word-valued fields, because these instructions inspect no values or calldata; raw admission binds and validates the fields separately.

Generate through the owner, never hand-edit generated files. Complete all package files before `development-run.py` snapshots selected checks. Supporting machine/trace modules must be rechecked in the eventual full retained graph. Decoder/engine composition, body control/memory/external/error/output semantics and retained public bytecode coverage remain open. No physical-resource or deployment claim follows.
