# sortWords raw decoder development

The owned generator extracts five exhaustive malformed single-bytes decoder classes from the pinned Collections runtime. Admission and Boundary compose these classes with the separately proved actual dispatcher and accepted decoder. Loose offsets, calldata gaps and trailing bytes follow compiler behavior.

This package provides development evidence only. Complete alignment, allocation, merge execution, serialization and retained public evidence remain open. Calldata must fit below 2^64; resource and instruction-interpretation assumptions remain explicit. No gas or performance claim follows.

Generated files must only be produced by generate.py. Finish package files before a development snapshot and preserve all live and retained graphs.
