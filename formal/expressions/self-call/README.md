# Encoded self-call composition

Compose runs the source-connected admission/canonical evaluator for the exact
graph, core, result index and parameter array represented by the decoded input.
It converts an admission rejection to its proved ABI error bytes, or takes the
recursive evaluator's produced value/error. The self-call receipt's success and
returndata are constructed from that computed result rather than supplied as
an unrelated observation.

Install substitutes that known self-call summary only at its exact request and
caller history. Every other call observation, balance query and decoder function
is preserved. The encoded entrypoint theorem then yields the exact wrapper
verdict: inner success returns identical bytes; ordinary failure produces
NodeCallFailed with index zero, self target, exact calldata and reason; sampled
exhaustion or the reserved signal propagates unchanged. Caller gas samples are
explicit inputs, not calculated costs or universal physical-out-of-gas claims.

Successful values retain canonical encoding guarantees from the declared graph
types. Covered is true for admission rejection and otherwise equals the inner
execution's coverage flag. Source primitive correspondence is asserted only
when this excludes every mathematical fallback receipt in the generated trace.

This is composition of source summaries. The decoded input is tied to the same
configuration, and the known self-call uses that inner evaluator with code
present. Applying this substitution to EVM execution still requires the recorded
source/ABI/call-transition and memory projections and adequate resources; it is
not a bytecode identity theorem. Actual inner external/guarded frame observations
and validation rejection bytes remain premises of the recursive configuration.
Guarded cache ABI and frame provenance, plus graph/tree equivalence under context
determinism, remain outstanding.

This proof-only package audits complete unchanged dependency source, tools,
retained artifacts and native declarations. It adds no new EVM or actual-source
fault campaign and changes no production code.
