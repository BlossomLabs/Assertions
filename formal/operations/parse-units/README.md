# Operations decimal unit parsing source correspondence

Both public unit parsers, the complete `_parseUnits` scanner, signed restoration and panic helper ASTs are gated. Source-derived sign, precision, point, digit validation, clipping, sticky remainder, accumulator, scaling and rounding controls drive the actual loop. An independent recursive scanner preserves first-error/overflow order and exact magnitude. It admits one decimal point and at least one digit, ignores excess fractional digits while retaining whether any was nonzero, scales by a proved safe power of ten, and rounds away from zero only for positive Ceil or negative Floor. The signed public return composes the freshly checked full-domain signed restoration theorem.

The domain is every finite uint256-length byte input, every uint256 precision and valid decoded rounding enum 0..2. Bare signs/points, negative unsigned zero, duplicate points, full-width boundaries and overflow remain explicit outcomes. There is no sampling, digit-count or loop/fuel bound. Faithful decoded calldata and enum validity, source/default initialization, byte/integer casts, checked multiply/add/power/increment primitive semantics, outer ABI/custom-error/panic serialization and sufficient resources are premises. Restricted compiler AST translation is reviewed conditional correspondence, not a certified Solidity translation.

Retention requires fresh native checks of all included/local declarations and immutable inputs/tools/AST/selectors, zero audit, two EVM fixture tests and two compiler-admissible semantic mutations rejected by the scanner's native semantics and EVM. Exact bytecode, gas, deployment and performance are separate.
