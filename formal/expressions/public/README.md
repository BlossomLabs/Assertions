# Public Expressions source composition

The generated direct-entry adapter binds the exact validator rejection function
after admission has produced the descriptors. Its public interface no longer
accepts an arbitrary rejection function. Admission rejection carries the exact
encoded error; evaluation returns the canonical node value or the precise
propagated failure.

`Connection.Evaluate` constructs complete validation and guard evidence when the
generated primitive trace is Covered and all reached successful bodies satisfy
`Model.Room`. Complete evidence contains the entire recursive entry trace,
canonical entry caches, an exact source-validator receipt for every cold node,
and every typed guarded attempt's success/adoption or failure/rollback. Failure
classification uses the derived next outer event and its actual observation.

Uncovered traces and insufficient modeled resource premises remain explicit
outcomes of proof construction. Their mathematical results are not claimed as
source-certified executions. Room is a per-reached-body representability and
CursorRoom condition, not a bound on physical gas.

`Encoded.Compose` connects the encoded source wrapper to that direct evaluation
at one modeled self-call observation. Malformed input rejects with empty bytes;
success forwards the exact value; ordinary failure is wrapped in NodeCallFailed;
sampled exhaustion propagates the signal. The installed observation is explicit,
and faithful EVM caller/static/decoder/gas projection remains a premise.

The guarded source adapter authenticates the caller before accessing the cache
or binding the validator. Foreign callers receive the exact NotSelf bytes.
For self calls, incoming canonical cache/metadata premises and per-body resource
premises support complete validator receipts. Reachable typed incoming caches
are supplied by the direct evaluator's complete frame evidence. Successful
guarded returns preserve both value and all cache fields through the ABI tuple.

Return-memory objects for direct/encoded assembly tails and Fits for guarded ABI
returns remain explicit. Graph/tree equivalence and exact compiled bytecode are
separate work. This composition adds no EVM or production source-fault campaign.

`generate.py` records reversible adapter selection and instantiation changes.
`verify.py` checks source/dependency/tool hashes, control erasure, complete native
declaration coverage, audit, formatting and unchanged inputs. Only a passed
retained manifest establishes completed verification.
