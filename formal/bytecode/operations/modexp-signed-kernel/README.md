# Modular-power signed-dimension kernel preparation

Independent finite-word magnitude, exponent parity and signed-result representation for the four powMod overloads, including int256.min. A residue strictly below the nonzero signed modulus magnitude stays in the signed range, with the sign chosen by negative base and odd exponent. This mathematical preparation does not connect any actual opcode path, prove inverse existence, or add public bytecode coverage. Complete native graph and wrapper/loop/error/physical return composition remain open.
