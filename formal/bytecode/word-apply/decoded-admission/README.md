# Decoded word apply admission connection

Composes both actual decoded public wrapper calls, the checked source alignment prefix and the finite valid-window loop. The theorem starts at the actual decoded entryPC1050/784 and ends atPC12235 with unchanged memory and the complete compiler stack frame. Every window offset is checked in input order, including the empty source case; the exact trace length is69 +53 times the number of windows.

Premises are explicit: source length divisible by32, fitting window input representation, template length at least32, each offset within template length minus32, reviewed bytecode interpretation and sufficient execution resources. This is a development connection, not complete raw public evidence. Allocation, empty return, target checks, template copy, callbacks, errors and output remain open.
