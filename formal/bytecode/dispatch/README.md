# Exact runtime dispatcher control

The Collections conditional source proof is complete. The separate exact
compiled-bytecode semantics track is still open. A completed result for this
package requires a passed retained manifest from `verify.py`; development logs
alone cannot establish that result.

`identity.py` recompiles each canonical Hardhat compiler job with its original
settings and current input sources into an isolated output directory. Full runtime
bytes, including metadata, must match the existing artifacts. The shared
Assertions/Collections job contains an older unused Expressions input: the runner
refreshes that input in its isolated request and records the change. All other
inputs, including versioned npm library sources, are matched to current files.
No production contract, artifact, build information or deployment is changed.
Runtime identity alone proves no semantic property.

`inventory.json` freezes all 49 selectors and their declared branch destination
addresses: Assertions 17, Expressions 3, Collections 29. The expected table is
independent of candidate bytecode generation, so a redirected branch cannot update
its own oracle. An entry address here is the baseline dispatcher branch destination;
it is **not** a proof that the subsequent wrapper decoder/body implements the
corresponding source function.

`generate.py` walks every exact runtime dispatcher instruction from PC zero,
retaining both arms of every condition. Unsupported reachable opcodes, invalid
jump destinations, wrong selector inventory or changed baseline bytes are rejected.
It emits all reachable symbolic stack/path states and per-instruction connection
lemmas. Code is represented by an indexed byte function and sequence constructor:
a long nested sequence literal defeated solver instantiation in the first
experiment. Generated files are never hand-edited.
Reachable-state predicates stay opaque until the individual connection lemma
reveals them. Finite destination predicates provide explicit quantifier triggers
for jump membership; each taken conditional jump also proves its byte is JUMPDEST.
PUSH immediate arithmetic widens bytes to naturals before assembling words.

`Machine.dfy` specifies a control/stack projection of the reached EVM instructions,
including top-first comparisons, PUSH immediates, DUP/POP, call value/calldata size,
loading word zero, SHR 224, conditional jumps and zero-length REVERT. It records the
initial MSTORE(64,128) but assumes its successful physical memory projection.
`Run` executes actual generated bytes through `Step`, carrying a proved reachable
state invariant. Every continuing step increases PC within the prefix, so termination
uses a well-founded PC ranking, rather than a dropped loop/fuel bound. Successful
routing retains the selector on the stack and the initialized free-memory pointer.
Short calldata, nonzero call value and unassigned selectors must reject; assigned
selectors must reach their frozen declared entry address.

Inputs are arbitrary 256-bit call values, calldata lengths and loaded words. Real
calldata constrains the word for short frames, but those frames reject before the
load, so the larger abstract domain is conservative. Required premises include
faithful byte extraction/instruction-boundary scanning, the reviewed reached-opcode
EVM control/stack interpretation, successful initial memory-store projection,
adequate reached execution resources, and truthful environment opcodes. The current
projection rejects unmodeled instruction shapes rather than approximating them as
success; native proofs must show no such state is reachable.

`verify.py` freezes the finished package, canonical artifacts/build inputs and
current compiler sources before execution. It requires all three native runs,
the shared instruction model, zero audits, exact byte/selector source gates,
runtime reproduction, complete native declaration inventories and unchanged
input/tool hashes. Its 168 EDR fixtures cover every selector with short and extended
frames and nonzero value, all lengths below four, and three unassigned selectors.
The EDR installation stays local; executable/native-binding hashes and the lockfile
are retained and checked again at completion.

The mutation campaign redirects the LEN equality branch to PAYLOAD and bypasses
short-frame admission. Each candidate must translate successfully, fail a native
semantic postcondition covered by the successful baseline, and produce an actual
wrong-entry EVM trace against the frozen oracle. A timeout, translation failure or
polling timeout is not detection. Never restart a live run because polling ends.
Finish package files before snapshotting and preserve every failed/incomplete run.

This dispatcher result will stop before ABI argument decoding or function bodies.
It cannot close full runtime semantics, resource safety, gas, deployment, complexity
or performance claims. Remaining wrapper/decoder/body/callback/memory/serialization
connections require further exact-bytecode proofs.
