# Arbitrary nonempty callback receipt memory

The hand-written memory component follows the actual free-pointer update, receipt length header and RETURNDATACOPY for any nonempty full returned byte sequence within the explicit fitting resource bound. It preserves the full bytes, including lengths other than32, and derives the fitting heap needed by the subsequent error packet. The caller heap may extend beyond its free pointer.

This is development verification only. Actual receipt controls, empty receipt behavior, failed receipts, raw loop composition and fresh full retained evidence remain open. Representation/resources and truthful external observations remain explicit; no gas/deployment/performance claim.
