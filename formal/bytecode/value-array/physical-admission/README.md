# Complete finite raw decoder development fixtures

Ninety complete EVM calls: sixteen independently encoded canonical pack/unpack outputs and seventy-four malformed unpack raw frames spanning all nine ordered classes. Exact mapped opcode PCs, stack/memory projections and physical RETURN/empty REVERT slices are checked. Both accepted decoder paths retain the actual array-head stride. Native closure, all descriptor/value/error/loop semantics and retained checking remain open. No public credit.
